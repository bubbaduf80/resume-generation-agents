# Job Output Template

Each job-specific output folder should contain:

- `01-job-target-brief.md`
- `02-draft-resume.md`
- `02-draft-resume.pdf`
- `02-draft-cover-letter.md`
- `02-draft-cover-letter.pdf`
- `02-evidence-map.md`
- `03-review.md`
- `04-final-resume.md`
- `04-final-resume.pdf`
- `04-final-cover-letter.md`
- `04-final-cover-letter.pdf`
- `04-final-evidence-map.md`
- `04-finalization-notes.md`
- `decision-log.md`

Use `decision-log.md` to capture human choices, such as why a reviewer recommendation was accepted or rejected.
